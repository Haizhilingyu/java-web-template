# ROADMAP 批次工单（roadmap-batches）

来源：`docs/ROADMAP.md`（2026-09-18 规划拷问修订版）。术语表见 `CONTEXT.md`，会话注册表决策见 `docs/adr/0001-jti-session-registry.md`。

## 已敲定的关键决策（工单编写时已遵守）

- 部门：单部门多对一可空；业务键 parent+name；负责人为自由文本；删部门须无子且无用户；禁用不追溯
- 岗位：多对多；被绑定禁删；删用户级联清理关联
- 部门树筛选含全部子孙；数据范围"自定义"精确等于勾选集合
- 字典/参数：后端不加缓存；config 无内置消费点、不种无人读取的键
- 会话：jti 注册表（Caffeine、单实例、ADR-0001）；多会话并存不互踢；重启全失效
- @Log：注解在 core/runtime，切面与落库在 system
- 数据范围：core 提供 DataScope 条件构建器，service 层显式调用；生效点本批仅用户管理分页列表
- 公告：仅管理端 CRUD，无用户侧展示面
