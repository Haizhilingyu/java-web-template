# 0001 - JWT 会话注册表：可撤销令牌与单实例权衡

登录令牌采用 JWT，但纯无状态令牌无法支撑登出、强退、改密作废的即时生效。决定在 core/runtime 的 TokenService 签发时把 jti 登记进本地 Caffeine（TTL = 令牌过期时长），认证过滤器校验 jti 必须在册——令牌"默认有效、可被撤销"。

## Considered Options

- **纯无状态 JWT**（现状）：登出仅靠前端删 token，无法强退、无法改密作废旧会话。
- **Redis 集中注册表**：支持多实例，但给模板引入部署依赖，不符合当前定位。

## Consequences

- 注册表在内存中，**仅单实例部署有效**；将来多实例必须换集中存储（Redis 等）。
- 服务重启即丢失全部会话，所有在线用户需重新登录。
